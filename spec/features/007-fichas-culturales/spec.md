# 007 · Fichas Culturales Inmersivas

## Qué hace

Tarjetas deslizantes que combinan la receta paso a paso con contexto histórico, festividades asociadas y videos integrados. Experiencia inmersiva para descubrir la historia detrás de cada platillo.

## Por qué

La constitución define "Fichas Culturales Inmersivas" como uno de los tres pilares de la plataforma. Cada platillo no es solo una receta, es una ventana a la cultura.

## Criterios de aceptación

- [ ] Componente `FichaCultural` con diseño deslizante
- [ ] Sección de receta paso a paso
- [ ] Sección de contexto histórico
- [ ] Sección de festividades asociadas
- [ ] Video integrado (YouTube/Vimeo)
- [ ] Galería de imágenes
- [ ] Animaciones suaves (apertura/cierre)
- [ ] Responsive mobile-first
- [ ] Accesibilidad completa
- [ ] Tests de UI
