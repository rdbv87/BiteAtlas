# 002 · UI Foundation

## Qué hace

Configuración completa del sistema de diseño visual con Tailwind CSS, shadcn/ui y Radix UI. Incluye tokens de diseño (colores, tipografías, espaciados) y componentes base accesibles.

## Por qué

Establece la base visual consistente para todos los componentes de la plataforma. La constitución define una "paleta cartográfica minimalista" y "fuentes sans-serif de alta legibilidad" que deben materializarse en tokens reales.

## Criterios de aceptación

- [ ] Tailwind CSS configurado con tokens personalizados
- [ ] shadcn/ui instalado y configurado
- [ ] Radix UI disponible para primitivos de accesibilidad
- [ ] Tokens de diseño definidos:
  - Colores: neutros oscuros/claros + acentos cálidos (especias)
  - Tipografías: sans-serif para UI + editorial para textos
  - Espaciados y breakpoints responsive
- [ ] Componentes base disponibles: Button, Card, Input
- [ ] Responsive mobile-first verificado
- [ ] CSS global con variables para modo claro/oscuro
- [ ] Tests de renderizado para componentes base
