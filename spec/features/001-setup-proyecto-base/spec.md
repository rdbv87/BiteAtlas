# 001 · Setup del Proyecto Base

## Qué hace

Configuración inicial completa del proyecto BiteAtlas con Next.js App Router, TypeScript estricto, sistema de testing, herramientas de calidad de código y estructura de directorios predefinida.

## Por qué

Establece los cimientos sólidos del proyecto siguiendo el principio de "Cero Deuda Técnica Inicial" de la constitución. Un setup correcto desde el inicio evita retrabajo y garantiza consistencia.

## Criterios de aceptación

- [ ] Proyecto Next.js inicializado con App Router
- [ ] TypeScript configurado en modo estricto (`strict: true`)
- [ ] Vitest funcional con tests de ejemplo
- [ ] ESLint configurado con reglas estrictas
- [ ] Prettier configurado para formateo consistente
- [ ] Husky + lint-staged configurado para pre-commit hooks
- [ ] Estructura de directorios creada: `src/components`, `src/services`, `src/types`, `src/scripts`, `src/errors`
- [ ] Archivo `.env.example` con variables de Firebase (sin valores reales)
- [ ] Comandos funcionales: `npm run dev`, `npm run test`, `npm run lint`, `npm run build`
- [ ] README.md actualizado con instrucciones de setup
