# 008 · Ecosistema de Aportes Comunales

## Qué hace

Módulo seguro para que chefs locales, historiadores y guardianes de tradiciones aporten y curen el patrimonio culinario de su tierra. Incluye formulario de subida, validación de datos y flujo de curación.

## Por qué

La constitución define como objetivo "conectar a los usuarios con las tradiciones" y menciona "chefs locales, historiadores y guardianes de tradiciones que desean preservar el patrimonio culinario de su tierra". Este módulo es el puente entre el conocimiento local y la plataforma.

## Criterios de aceptación

- [ ] Formulario seguro de subida de platillos
- [ ] Validación Zod en todos los campos
- [ ] Upload de imágenes con preview
- [ ] Selección de país/región existente
- [ ] Flujo de revisión pendiente → aprobado/rechazado
- [ ] Panel de administración para curación
- [ ] Notificaciones a contribuidores (futuro)
- [ ] Rate limiting para prevenir spam
- [ ] Tests de formulario y validación
- [ ] Accesibilidad completa
