# 006 · Navegación Cartográfica Interactiva

## Qué hace

Mapamundi interactivo y ultrarrápido para explorar el mundo culinario. Navegación fluida por continentes, países y regiones con zoom suave y transiciones elegantes.

## Por qué

La constitución define "Exploración sin Fricción" como principio fundamental. La navegación cartográfica es el corazón de la experiencia BiteAtlas.

## Criterios de aceptación

- [ ] Mapamundi renderizado con librería de mapas optimizada
- [ ] Zoom fluido desde vista global hasta país/región
- [ ] Click en países muestra información básica
- [ ] Transiciones suaves entre vistas
- [ ] Responsive en desktop y mobile
- [ ] Datos de países cargados desde Firestore
- [ ] Performance: 60fps en navegación
- [ ] Accesibilidad: navegación por teclado
- [ ] Tests de renderizado y navegación
